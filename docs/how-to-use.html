How to use tabellion

Put analysis results into G-BA dossier modules on Linux, without Word. Every edit to an existing docx comes back as tracked changes for the team to review.

Pick a route

Start a module from the template

You write Typst and build makes the docx. Use this for a first draft.

rv run gba.R import modul4 dossier/m4
rv run gba.R build dossier/m4/modul4.typ

Edit a docx the team works on

You describe the changes as JSON and apply edits only those targets. Use this after the first handover.

rv run gba.R outline in.docx
rv run gba.R apply in.docx ops.json out.docx

The edit loop

1 MarkThe team types {{abb:km}} alone in a paragraph
2 Lookoutline lists text, tables, figures, placeholders
3 DescribeYou write ops.json
4 ApplyA failed check stops the run, with no output
5 ReviewThe team accepts or rejects in Word

The loop repeats. In a later round, your own pending changes are replaced, not stacked, and other people's changes are never overwritten.

Write ops.json

One file can hold many edits. Relative figure paths start at the folder of ops.json.

{
  "aenderungen": [
    {"op": "einfuegen", "platzhalter": "met:km",
     "text": {"baustein": "ereigniszeit", "werte": {"n": 12, "studie": "A"}, "tag": "met_km"}},
    {"op": "einfuegen", "platzhalter": "abb:km",
     "abbildung": {"datei": "km.png", "titel": "Kaplan-Meier OS", "tag": "abb_km", "breite": "14cm"}},
    {"op": "einfuegen", "platzhalter": "tab:os",
     "tabelle": {"titel": "OS", "tag": "tab_os", "kopf": [["Arm", "N"]], "zeilen": [["A", "12"]]}},
    {"op": "werte", "ziel": {"tag": "tab_pfs"},
     "tabelle": {"kopf": [["Arm", "N"]], "zeilen": [["A", "13"]]}},
    {"op": "titel", "ziel": {"tag": "tab_pfs"}, "titel": "Progressionsfreies Überleben"}
  ]
}
OperationTargetEffect
einfuegen{{name}}Turns the placeholder into a table, figure, or text block
ersetzentag or blockMarks the old table, figure, or text as deleted and adds the new one
wertetableChanges only the cells that differ. Needs the same table shape
titeltable or figureChanges the caption text. The number stays
felderwhole fileRefreshes fields with no other change, for example after a reject in Word

Everything is under the author Automatisierung. Numbers, cross-references, and contents text refresh on every run that changes the file. Those refreshes are not tracked.

Target by tag or by block

Tag

Anything tabellion inserted can carry a tag. Tags survive Word saves, so one ops.json works round after round.

"ziel": {"tag": "abb_km"}

Block

For untagged content, take the id from outline. It only holds for that exact file, so sha256 goes with it.

{"sha256": "<from outline>", "aenderungen": [
  {"op": "ersetzen",
   "ziel": {"block": "b0150", "bis": "b0152"},
   "text": {"baustein": "subgruppen",
            "werte": {"alpha": 0.05}}}]}

Add a text block

Text blocks live in typst/methoden.typ. The ones there are lorem ipsum for now. Each takes values from your analysis, and a missing value stops the run.

#let bausteine = (
  ereigniszeit: w => [
    Analysiert wurden #w.n Personen aus #w.studie.
  ],
)

The same blocks work in Typst, inside an answer:

#antwort("b0141")[#baustein("ereigniszeit", werte: (n: 12, studie: "A"), tag: "met_km")]

When a run stops

SituationWhat to do
Someone else has pending changes in the targetAccept or reject them in Word, then run again
The target holds an EndNote citationChange it in Word, or confirm with "zitate_loeschen": true
The text holds a formula or section break, or sits inside a fieldChange it in Word
The target is a question, explanation, or headingLeave it. The G-BA rules require those blocks
The table has a different shapeUse ersetzen instead of werte
Still needs Word: page numbers, and adding citations. After rejecting changes, run felder or press F9 in Word to refresh numbers and contents text.
